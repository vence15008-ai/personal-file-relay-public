# 中转站 Windows 客户端：副机使用

本包是 x64 免安装客户端，连接使用本仓库搭建且已运行的主机。请先按仓库主机指南准备自己的服务；普通上游二进制不含本定制版的中转站界面。文件保存在自己的主机上，副机不需要安装 Tailscale 或 FileBrowser。

## 第一次使用

1. 将整个 ZIP 解压到独立目录，例如 `D:\Apps\PersonalRelay`。不要直接在压缩包里运行，也不要只复制 EXE。
2. 双击 `RelayClient.exe`。
3. 点窗口右上角齿轮，将「服务地址」改为自己主机的 HTTPS 根网址并保存。格式示例：`https://your-device.your-tailnet.ts.net`，必须替换为自己实际获得的网址。
4. 由本人输入原有中转站账号和密码登录。这里不需要 GitHub 密码；本包不包含任何账号密码或登录会话。
5. 想固定到任务栏时，右键运行中的任务栏图标，选择「固定到任务栏」。

上面的域名仅作格式示例，不能直接使用。以后主机地址改变时，在齿轮设置中填写新的 HTTPS 根网址，不要加 `/chat` 或 `/files`。发布包不提供公共网盘账号或公共文件主机。

## 系统要求

- Windows 10 / 11 **x64**；此包不适用于 32 位 Windows、Windows ARM 原生运行、macOS 或 Android。
- .NET Framework 4.8；若系统缺少，请从 [微软官方页面](https://dotnet.microsoft.com/download/dotnet-framework/net48) 安装。
- Microsoft Edge **WebView2 Runtime**。若提示找不到运行时，请从 [微软官方下载页](https://developer.microsoft.com/microsoft-edge/webview2/#download-section) 安装 Evergreen Runtime x64，然后重开客户端。安装 Edge 浏览器不等于运行时检测通过。
- 本机实测为 Windows 11、175% 显示缩放；其他电脑和 Windows 10 尚待实机验证。背景模糊取决于系统支持和透明效果设置，Windows 10 不承诺相同效果。

本地构建程序尚无代码签名证书。如遇系统提示，先核对本私有仓库的发布来源及附件 SHA-256；无需关闭杀毒软件或防火墙。

## 常用操作

- 默认最近 3 条，向下滚动看历史；点击消息正文或时间区域复制整条文字。
- 「预览」打开可选择文字的全屏预览；文件按钮直接下载、预览或删除。
- 「粘贴并发送」支持文字与图片；也可按 Ctrl+V。文件可以拖入窗口上传。
- 全局热键：`Ctrl+Alt+Space` 显示/收起；`Ctrl+Alt+Enter` 粘贴并发送；`Ctrl+Alt+U` 选择文件上传。齿轮里可修改，客户端需保持运行。
- 点 × 收到托盘；右键托盘「退出客户端」才完全退出。主机文件服务继续运行。

## 更新与移除

更新前先从托盘退出，备份原程序目录，再将新版完整解压到相同目录。不要覆盖或上传 `%LOCALAPPDATA%\PersonalFileRelay\Client`，这里有个人连接设置和 WebView2 登录资料。

移除时退出客户端，删除自行解压的程序目录，并取消任务栏固定/删除自己创建的快捷方式即可。默认保留上述个人资料目录；移除客户端不会删除主机文件。

## 连不上时

主机必须开机、联网、文件服务和 Funnel 在线。先在浏览器打开同一 HTTPS 网址；若浏览器也不通，请检查主机。不要在副机填写 `127.0.0.1:18473`，该地址只指向副机自身。

Funnel 是公网入口，靠中转站账号密码保护，不是仅同 Tailscale 账号设备可见。私人云盘不等于备份，传输速度受主机家庭上行带宽和 Funnel 限速影响。

## 图片拖出与免重复登录

主机需更新到包含此功能的定制版。按住图片文件名行拖到目标应用的附件区；首次保持鼠标按住等待准备，松开过早则准备后再拖一次。最大单图 32 MiB，拖出是复制；具体目标应用需实测支持文件拖入。

登录时可勾选“记住此设备 90 天”，或在齿轮 → 登录设备输入当前密码授权。每台浏览器 / 客户端单独授权、单独撤销；清除网站数据后需要重新授权。显式退出忘记当前设备；修改或重置密码使旧设备授权失效。共享电脑不要选择记住。
