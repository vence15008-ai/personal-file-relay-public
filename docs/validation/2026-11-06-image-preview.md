# 2026-11-06 图片预览修复与验收

本次检查范围为中转站的图片查看流程。旧版在浏览器和原生WebView2中能显示合成PNG/JPEG/WebP，未复现用户那张真实图片完全无法显示；但确认点击预览会进入完整文件管理，并请求2–3张原图（含相邻图片）。

改动：中转站内只预览当前图片，默认最长边1024px，主动点击才加载原图；关闭/切换取消请求并释放Blob URL；超时与错误提供重试，预览期间暂停5秒列表轮询。后端两处“小压缩文件直出原图”均改为按实际像素判断，旧缓存里超尺寸图片按需重生成。

Terra6.1使用独立18475服务、临时账号、合成内容及独立浏览器/WebView2资料验证：PNG/JPEG/WebP、中文空格&文件名、高熵8MP JPEG、低字节8MP PNG均可显示；保持/chat，单次xlarge预览，不请求相邻原图；显式原图、415/500重试、请求中关闭、快速切换防旧图回写、6.2秒无列表轮询、短Cookie丢失后的90天凭据恢复均通过。30秒超时分支通过加速到250ms的挂起测试验证，未自然等待30秒。
