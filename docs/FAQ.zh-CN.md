# Personal File Relay 常见问题

最后核对：2026-11-05。当前客户端发行版：[client-v0.1.1](https://github.com/vence15008-ai/personal-file-relay-public/releases/tag/client-v0.1.1)。[返回首页](../README.md)。

## Personal File Relay 是什么？

它是基于 FileBrowser Quantum v2.0.2-stable 定制的个人文件、图片与文字中转站。Windows 主机保存数据，其他设备通过 HTTPS 浏览器访问，也可以在 Windows 副机运行窄版客户端。上游项目与本定制版的功能范围分别记录，不能直接套用旧版 File Browser 的配置。

## 其他电脑需要安装服务器或 Tailscale 吗？

副机不需要。浏览器直接访问主机 HTTPS 网址；想要窄窗、全局热键与任务栏入口时，下载 Windows x64 客户端。只有保存数据并提供服务的主机运行文件服务和 Tailscale。参见[快速开始](../desktop/windows/QUICKSTART.zh-CN.md)。

## vivo 手机开着其他 VPN，还能上传下载吗？

方案不要求手机安装或切换到 Tailscale，手机使用普通 HTTPS 网页。但具体 VPN 路由、DNS 与蜂窝网络可能影响连接，应在本人手机上保持现有 VPN、关闭 Wi-Fi 后测试登录、上传和下载。本机访问公网网址不能代替这项验证。

## 手机上传显示 401 / no token present in request 怎么办？

这表示请求没有有效登录凭证，不能据此判断图片格式或大小有问题。长时间后台、会话到期、浏览器清除 Cookie，或换到另一个浏览器 / Web App 都可能需要重新登录。先刷新或重新打开原网址，由本人重新登录，再选择测试图片上传；不要把密码或令牌发到聊天或 Issue。

主机更新到包含会话修复的版本后，页面恢复前台 / 从返回缓存恢复时会检查会话；受保护 API 的 401 会返回登录页并保留中转站返回路径，失效后不会继续启动排队上传。临时网络错误或服务端 500 不会被当作登出。修复没有延长登录有效期，也没有把凭证移到 localStorage。仅重新下载 Windows 客户端不能替代主机文件服务的网页代码更新。

## 安卓有 APK，Mac 有原生 App 吗？

当前没有独立 APK 或 Mac 原生包。安卓可以在兼容浏览器中添加 Web App 到桌面；部分 vivo 浏览器只创建快捷方式。Mac 使用网页，支持的浏览器可安装 Web App。Web App 仍需联网、主机在线及登录。

## 没有输入框，怎么传一段文字或一张图片？

先复制，再点「粘贴并发送」；电脑也可用 Ctrl+V。剪贴板有支持的图片时进入上传队列，否则发送文字。浏览器若不允许读取图片剪贴板，可改用上传或拖入文件。点击消息正文或时间区可复制全文，预览页可选择部分文字。

## 会在后台自动同步或读取剪贴板吗？

不会。只有本人点击发送、执行粘贴或按下已配置的发送热键时读取。全局热键需要 Windows 客户端正在运行。文件列表会刷新，但这不等于自动同步剪贴板或文件夹。

## 单个 200 MB 文件能传吗？有分块上传吗？

已用 209,715,200 字节（200 MiB）合成文件完成上传下载并核对 SHA-256，实际观察到 20 个 10 MiB 上传块。它说明当前测试条件下的大文件链路通过，不代表任意网络、任意大小或断线续传都经过验证。参见[验证记录](VALIDATION.md)。

原生发送热键对编码后的剪贴板 PNG 设置 32 MB 保护上限，以控制原生消息通道的临时内存；超过时可走普通文件上传。文字发送上限为 32,000 UTF-16 代码单元，列表字符数按 Unicode 码点统计。

## Funnel 只允许我同账号的设备访问吗？

Funnel 提供公网入口，访问者可以不在自己的 Tailscale 网络里；**文件权限由中转站账号密码控制**。当前部署关闭匿名访问、自助注册和公开分享；未登录的列表、文件直链、消息目录及上传 API 已验证被拒绝。网络含义以 [Tailscale 官方说明](https://tailscale.com/kb/1223/funnel)为准。

## 文件和消息存在哪里？会共享整个硬盘吗？

文件位于主机安装根目录的专用 `files` 文件夹；消息以独立文件保存在 Personal 源的 `.text-relay` 子目录。应只配置这个专用文件源，避免把整盘或用户资料根目录暴露给服务。网页默认列表聚合根目录文件与最近消息，完整目录操作在文件管理页。

## 不买域名、不租服务器也能使用吗？

有可用的 Tailscale 账号和 Funnel 权限时，可以使用其分配的 `ts.net` HTTPS 网址，不必为该方案新增域名或服务器。Funnel 的可用条件和速率限制应查看[官方文档](https://tailscale.com/kb/1223/funnel)。主机原有网络、供电与数据备份仍需自行提供。

## 主机休眠、关机后还能访问吗？

不能。主机须开机、联网且文件服务与公网入口保持运行。允许熄屏；更改接电睡眠、合盖、休眠或电池策略前应由主机所有者确认。关闭副机客户端不会关闭主机服务。

## 原生运行意味着总共只占几十 MB 内存吗？

不能这样理解。Go 文件服务与 Windows 客户端分开运行；客户端还有多个 `msedgewebview2` 浏览器引擎进程，应分别测量工作集和私有字节。一次正式服务空闲快照的工作集为 64.8 MiB，不能当作包含客户端的总内存或传输峰值。测量范围见[验证记录](VALIDATION.md)。

## 能代替备份或端到端加密聊天吗？

不能。消息作为主机文件保存，HTTPS 传输不等于消息端到端加密。私人云盘应另有独立备份；数据库备份须停服务或使用一致性备份。传输速度受主机家庭上行带宽和 Funnel 限速影响，也不提供聊天消息送达保证。

## 公开仓库一定会被搜索或 AI 收录吗？

不会保证。公开仓库提供可访问的源码和说明，但搜索抓取、索引与 AI 引用由各平台决定。`llms.txt` 只是文档入口，不提供排名或推荐保证；项目会持续维护清晰的功能、来源和验证边界，见[SEO / GEO 维护说明](DISCOVERABILITY.md)。公开代码也不会开放使用者自己的文件服务权限。
