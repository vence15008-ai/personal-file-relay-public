# 公开发行版本说明

维护日期：2026-11-05。公开仓库提供 Personal File Relay 的源码与 Windows x64 客户端，采用独立的 Git 初始历史。

## 发布范围

- FileBrowser Quantum v2.0.2-stable 基线上的定制源码、部署脚本和文档。
- 使用合成文件生成的浅色/深色界面截图与本机验证记录。
- Windows 客户端ZIP、泛化的快速开始和SHA-256附件；包内保留Apache-2.0、上游修改摘要及WebView2许可说明。

公开内容使用示例域名。安装者需要自己的Windows主机、文件服务账号与Funnel网址；本项目不提供公共文件主机或共享账号。程序默认回环地址只指向运行客户端的本机。

## 检查方法

发布前使用Gitleaks扫描当前源码、独立Git历史和解压后的客户端包，并检查个人地址、资料路径、登录数据文件与常见凭证字面量。上游的7项已知扫描命中涉及公开演示JWT、测试配置与翻译字符串，已按原文件Git blob与官方v2.0.2-stable逐一比对，未当作使用者真实令牌。

扫描不能证明不存在所有敏感信息或漏洞。本机功能验证及未完成的实体设备测试见[验证记录](VALIDATION.md)。本记录不声明已完成完整漏洞审计或全部第三方素材的逐项法律审查。

## 发行管理

当前公开客户端tag为`client-v0.1.1`。源码由该tag标记，包内`RELEASE.json`记录对应提交与客户端哈希。只上传明确列入白名单的程序、依赖、许可证和说明文件，不复制运行时数据库、WebView2资料、Cookie、日志或使用者文件。

保留既有tag，修订说明或程序时发布新版本。仓库源码与个人运行服务独立，公开发行不会修改任何已部署主机的文件范围或认证。
